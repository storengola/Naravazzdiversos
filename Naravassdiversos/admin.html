Como usar este painel

Use este painel para actualizar produtos, preços, zonas de entrega, textos do site e fotos. As alterações só ficam visíveis para todos os visitantes depois de carregar em Publicar na loja.

1. Entrar

  • Abra esta página e introduza a palavra-passe do admin.
  • Para mudar a palavra-passe: menu Definições → secção Segurança.
  • No telemóvel pode adicionar esta página ao ecrã inicial para abrir mais depressa.

2. Fluxo normal (recomendado)

  1. Faça as alterações (produtos, entregas, textos ou fotos).
  2. Opcional: Guardar rascunho - grava só neste telemóvel/computador para pré-visualizar a loja no mesmo browser.
  3. Abra a loja noutro separador e confirme que está correcto.
  4. Carregue em Publicar na loja e confirme. A loja pública actualiza para todos.

Sem Publicar na loja, os clientes continuam a ver a versão antiga.

3. Produtos

  • Menu Produtos → + Novo produto ou Editar num produto existente.
  • Preencha nome (PT e EN), preço em Kz, categoria, marca, descrição e imagem.
  • Para a foto: use Carregar imagem ou cole o endereço da imagem no campo correspondente.
  • Apagar remove o produto do catálogo (depois de publicar).
  • Pesquise ou filtre por categoria para encontrar itens mais depressa.

4. Zonas de entrega

  • Menu Entregas → adicione ou edite zonas (nome + preço em Kz).
  • Estes valores aparecem no checkout quando o cliente escolhe a zona.

5. Textos do site (PT e EN)

  • Menu Textos → altere títulos, frases do hero, promoções, etc.
  • Há colunas em português e inglês - actualize as duas quando fizer sentido.

6. Imagens do site (hero, promo, categorias…)

  • Menu Imagens do site → cada caixa é uma foto da loja (hero, banner promo, categorias, foto da Nara, galeria, etc.).
  • Carregar envia uma foto nova e coloca-a nesse espaço automaticamente.
  • Escolher da média usa uma foto já carregada na biblioteca (sem copiar links).
  • Depois: Guardar rascunho e Publicar na loja.

7. Fotos de produtos e biblioteca (Média)

  • Menu Média → carregue ficheiros a partir do telemóvel ou computador.
  • Use essas fotos nos produtos ou escolha-as em Imagens do site.

8. Botões no topo / fundo do ecrã

  • Guardar rascunho - só neste dispositivo (pré-visualização).
  • Publicar na loja - envia o catálogo para a loja online. Pode pedir a palavra-passe outra vez.

9. Dicas no telemóvel

  • Os botões Guardar / Publicar ficam fixos em baixo para serem fáceis de tocar.
  • Na lista de produtos, use os cartões (mais legíveis no ecrã pequeno).
  • Use uma ligação estável (Wi‑Fi) ao publicar ou carregar fotos.

10. Quando algo corre mal

  • Se a publicação falhar, a loja não abrir bem, os preços não actualizarem, ou não souber o que fazer: contacte o criador / programador do site (a pessoa que lhe deu acesso a este painel).
  • Descreva o que tentou fazer e, se possível, envie uma captura de ecrã da mensagem de erro.
  • Não partilhe a palavra-passe do admin com pessoas que não devem editar a loja.
